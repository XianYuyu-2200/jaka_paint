# JAKA Paint Project Instructions

Before changing this project, read the reusable prompt block in `AI_DEVELOPMENT_PROMPT.md` and follow its scope, testing, and safety constraints. Ignore the task template below that prompt block unless the user explicitly chooses it as the current task.

If the prompt file is missing, unreadable, or malformed, report that problem instead of silently skipping the instructions. The stage list is a task menu, not permission to implement every stage. Without a current task, run only the baseline checks in stage 0 and suggest one next step. After completing the requested task, report results and wait for the next task. Explicit user instructions take precedence, including an authorized baseline update spanning multiple modules.

- Inspect the actual code and preserve work the user has already completed. Work within the explicitly requested scope. For a clear task, state a short plan and proceed; ask only for missing information that blocks implementation.
- The baseline already includes a parameter settings window and `core/parameters.py` validation. Applied parameters are session-only and reset to defaults on restart. Reuse `app.conversion_parameters` and the existing apply/validation flow; do not treat parameter UI as an unimplemented stage or introduce conflicting parameter stores.
- The baseline includes `core/image_client.py` and the complete original prompts in `core/image_prompts.py`. Local image import and the end-to-end photo-to-line-art UI are separate tasks. A client being present does not mean a generation button, background request, preview, or real network validation is complete.
- For image integration, read `docs/IMAGE_SERVICE.md` and reuse `generate_lineart(source, *, api_key=None, quality='high', timeout=240)`. Preserve the provided protocol and complete original prompts unless the user explicitly requests a verified change. Supported quality values are `medium` and `high`; use the actual client contract for source types.
- Reuse image service settings and read `app.get_image_generation_options()` on the UI thread before passing its snapshot to a worker. A missing key raises `ValueError`; handle it before a request. Keys remain in process memory or `XIANJIJI_API_KEY`, never on disk or in logs. Do not assume `.env` is loaded. No automatic image requests at startup, on image selection, or on parameter changes.
- Keep Tkinter responsive: run network work outside the UI thread, update widgets only on the main thread, prevent duplicate submissions, and handle results arriving after a window closes. Failed generation preserves valid prior images, line art, and TXT results. Validate and preview generated PNG data, then obtain user confirmation before adopting it for conversion.
- Preserve `core/lineart_to_points.py`, the `convert_to_jaka()` interface, generated JAKA TXT structure, and existing regression behavior unless the user explicitly requests a core conversion change.
- The sample-to-TXT flow must work without image-service credentials or network requests. Read relevant code and tests before editing. Run relevant offline tests, `python -m py_compile`, and feasible manual checks. Mock external service success and failure; do not make paid requests in automated tests. Report network, packaging, and hardware checks separately and only when actually performed.
- Keep the learner-facing application language product-focused. Do not label the application as a tutorial, teaching prototype, or unfinished Vibe Coding project.
- Do not invent controller APIs, device addresses, credentials, Tool IDs, User Frame IDs, coordinates, heights, speeds, or workspace limits. Existing device values are examples, not site calibration. Controller development requires matching official interface/version information and simulated checks before hardware validation; no controller client or simulator is currently provided by this baseline.
- Never add automatic power-on, enable, alarm clearing, interlock bypass, or automatic motion retry. Network connectivity is not proof that drawing completed; uncertain device state must remain visibly uncertain.
- Do not submit API keys, passwords, controller credentials, actual device addresses, or unconfirmed site coordinates. Do not inspect, decompile, or overwrite unrelated projects. Hardware validation belongs to the equipment lead under site procedures.
- Treat the directory containing this `AGENTS.md` as the project root, regardless of its local folder name. Do not modify unrelated projects outside this root for a JAKA Paint task.
